利用規約

この規約は、Otoverse Chat（以下「本サービス」）の利用条件を定めるものです。本サービスを利用した時点で、この規約に同意したものとみなします。

1. 本サービスについて

本サービスは、現在の Otoverse が発案される前に作られた試作（没案）を、個人の楽しみと記録のために公開しているものです。予告なく内容を変更・停止・終了することがあります。

2. AI との会話について

  • キャラクターの返答と音声は AI が生成したもので、実在の人物の発言ではありません。
  • 返答の内容は、必ずしも正確・安全とは限りません。医療・法律・金融など重要な判断には、本サービスを使わないでください。
  • キャラクターは架空の存在です。本サービスは、専門家による相談の代わりにはなりません。

3. データの取り扱い

  • 会話履歴：お使いのブラウザのローカルストレージに、キャラクターごとに保存されます。運営者のサーバーに保存されることはありません。ブラウザのデータを消すと、履歴も消えます。
  • 外部サービスへの送信：送信したメッセージ（添付した画像などを含む）は、返答を生成するために Google の Gemini API へ送られます。音声を作るときは、返答の文章が音声合成エンジン（AivisSpeech）へ送られます。送られた内容は、それぞれのサービスの規約に従って扱われます。
  • 音声入力：マイクを使う機能は、ブラウザが許可を求めたときだけ動きます。音声の認識はブラウザの機能が行い、運営者が音声を保存することはありません。
  • 個人情報（本名、住所、電話番号、パスワード、他人の情報など）や、機密情報は入力しないでください。

4. 禁止事項

  • 法令や公序良俗に反する行為、他者を傷つける行為
  • 他者の権利（著作権、肖像権、プライバシーなど）を侵害する入力
  • 本サービスや外部サービスに、過度な負荷をかける行為
  • 不正アクセスや、サービスの仕組みを悪用する行為
  • キャラクターに、過度に暴力的・性的・差別的な内容を言わせようとする行為
  • 商用目的での無断利用

5. 著作権・キャラクターの権利

キャラクター（音葉 万夏、エレナ）、画像、設定、名称、およびロゴの権利は、運営者（おとば！）に帰属します。無断での転載、再配布、改変、商用利用、AI の学習データへの利用はできません。ソースコードの利用条件は、リポジトリの LICENSE に従います。

6. 免責事項

  • 本サービスは現状のまま提供され、動作の継続や正確性、特定の目的への適合を保証しません。
  • 本サービスの利用、または利用できなかったことで生じた損害について、運営者は責任を負いません。
  • 外部サービス（Gemini API、AivisSpeech など）の障害、仕様変更、料金・規約の変更による影響について、運営者は責任を負いません。

7. 規約の変更

この規約は、必要に応じて変更することがあります。変更後に本サービスを利用した場合は、変更後の規約に同意したものとみなします。
